## **Descrição**
Este projeto busca aprimorar o entendimento de alguns conceitos, como a identificação de periféricos (no caso, o teclado), juntamente com o uso de threads. A princípio, foi descontinuado, mas, ao adquirir os conhecimentos necessários, irei finalizá-lo. A ideia inicial era criar um software capaz de coletar e identificar as entradas do teclado, seguindo o padrão UTF-8. Em seguida, ele deveria inseri-las em um arquivo .txt.
